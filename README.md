# Avinya

**Avinya** is a modern platform designed to help students and professionals find the best **Jobs**, **Internships**, and **Courses**. It provides a sleek, responsive dashboard to explore opportunities, track saved items, and get personalized recommendations to guide your career path.

## 🚀 Features

- **Dashboard:** An overview of available opportunities, quick stats, and tailored recommendations.
- **Responsive Design:** Fully functional across Desktop, Tablet, and Mobile devices.
- **Intuitive UI:** Built with modern design principles (glassmorphism, vibrant colors, smooth transitions).
- **Categorized Sections:** Dedicated pages for Jobs, Internships, and Courses.

## 🛠️ Technology Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Routing:** React Router DOM

## 💻 Getting Started

To run the project locally on your machine:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173/` (or the URL provided in your terminal).
